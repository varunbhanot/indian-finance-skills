# flag-basic-low

Basic at a quarter of fixed pay, below the authored floor of 40%, so
`basic-share` is raised.

`₹5,00,000 ÷ ₹20,00,000 = 25%`.

The flag carries the band's ceiling as well as its floor, because a band with
one end shown does not say what the other end is. Nothing else fires: no
variable pay, no one-time cash, no equity, nothing non-cash.
