# flag-variable-share

Variable pay at a quarter of CTC, which is at or above the authored threshold of
20%, so `variable-pay-share` is raised.

`₹4,00,000 ÷ ₹16,00,000 = 25%` — the components are basic ₹10,00,000, special
allowance ₹2,00,000 and the bonus itself.

Nothing else fires, on purpose: basic is 83.33% of fixed pay (well inside the
band), there is no one-time cash, no equity and nothing non-cash. The fixture
isolates one flag so a change to it shows up here rather than in a letter
raising six.
