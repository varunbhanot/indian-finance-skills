# A joining bonus lands in year one, and is named in the average it sits inside

No equity here, so the table is the four-year minimum. The ₹5,00,000 bonus is in
the first row's `one_time` and nil in every other row.

Both averages are reported, and this is the fixture that says why there are two:
`with_one_time` is a fact about the table as it stands and is not a recurring
figure — it holds ₹5,00,000 that arrives once — so it names the component
inside it in `one_time_components`, and `without_one_time` is the same average
with that component out of it. A one-time item is never averaged into a
recurring figure without being named (CONTEXT.md, "One-time component").

The variable pay shows the two bases apart: nil in the first, ₹4,00,000 in every
row of the second.
