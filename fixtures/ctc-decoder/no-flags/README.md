# no-flags

A plain letter under every threshold: basic exactly half of fixed pay (inside
the 40–50% band), no variable pay, no one-time cash, no equity, nothing
non-cash. `flags` is `[]`.

The negative case earns its place. Without it, a change that made some flag fire
on everything would still pass every other fixture in this directory, because
each of those asserts the flag it is named for and this is the only one
asserting the absence of all nine.
