# flag-clawback

A joining bonus recoverable within twelve months, so `clawback` is raised.

`kind` is **letter**, not `statute` or `heuristic`. No threshold decided this and
no Act requires it: the period is a fact the user typed off their own offer
letter, and the flag says so rather than dressing it as law.

The bonus is deliberately small — `₹2,00,000 ÷ ₹22,00,000 = 9.09%`, under the 15%
one-time threshold — so this fixture raises the clawback flag alone and
`fixtures/flag-one-time-share` covers the other.
