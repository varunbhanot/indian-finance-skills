# A listed option struck at the money is worth nil, with the reason

2,000 options at a ₹1,500 fair market value and a ₹1,500 strike: the spread is
nothing, so the grant is held at ₹0 against the ₹30,00,000 the letter claims.

This is the ordinary case, not the corner one — options are usually granted at
the money. `method` is `intrinsic-value` and the assumption says so, so a ₹0 is
read as "worth nothing today" rather than as a missing figure.
