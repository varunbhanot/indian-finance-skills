# Listed RSUs with no unit count: the claim, taken as the grant-date value

The same instrument with `units` and `grant_date_fair_market_value` left out,
which is how most letters state a grant. The claimed value stands in, and
`method` is `claimed-as-grant-date-value` so the reader can see the figure rests
on the letter rather than on a market quote.

The schedule is back-loaded — 5/15/40/40 — which is why ADR 0005 refuses to
average a grant over its years: year one is nothing like the four-year mean.
