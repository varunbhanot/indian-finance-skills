# Unlisted equity: nil, named, and never dropped

A startup ESOP grant the letter values at ₹80,00,000. There is no market price
to value it at, so it is held at ₹0 with `method` `unvaluable` — and it is still
in `components`, still in `equity_as_claimed`, and counted in
`unvaluable_equity` at what the letter claimed.

Both halves of ADR 0005 are here: the decoder does not invent a number for the
most inflated line on the page, and it does not quietly drop it either.
